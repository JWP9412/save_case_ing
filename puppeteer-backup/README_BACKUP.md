# 💿 백업 폴더 (Backup Folder)

이 폴더는 이전 버전의 Puppeteer 코드를 백업하기 위한 폴더입니다.

**생성일**: 2025-11-13  
**용도**: 코드 복구 및 참고용

---

## 📂 폴더 내용

```
puppeteer-backup/
├── BrowserManager.js           이전 버전 브라우저 매니저
├── index.js                    이전 버전 메인 스크립트
├── PageController.js           이전 버전 페이지 컨트롤러
├── ParallelProcessor.js        이전 버전 병렬 처리기
├── parallel-cases.test.js      병렬 처리 테스트 파일
├── single-case.test.js         단일 사건 테스트 파일
└── src/                        (빈 폴더)
```

## 🎯 용도

### 1️⃣ **코드 복구**
현재 버전에서 문제가 발생했을 때 이전 버전 코드를 참고하거나 복구할 수 있습니다.

### 2️⃣ **기능 비교**
새 기능과 이전 기능을 비교하여 개선점을 확인할 수 있습니다.

### 3️⃣ **테스트 참고**
테스트 파일을 참고하여 새로운 테스트를 작성할 수 있습니다.

---

## 📄 파일 설명

### `BrowserManager.js` (이전 버전)
- **역할**: 브라우저 인스턴스 관리
- **주요 기능**:
  - 브라우저 생성 및 종료
  - 인스턴스 풀 관리
  - 리소스 관리

### `index.js` (이전 버전)
- **역할**: 메인 자동화 스크립트
- **주요 기능**:
  - 초기화 로직
  - 사건 처리 워크플로우
  - 에러 처리

### `PageController.js` (이전 버전)
- **역할**: 페이지 자동화 로직
- **주요 기능**:
  - 페이지 이동
  - 요소 찾기 및 클릭
  - 데이터 입력
  - 스크린샷 캡처

### `ParallelProcessor.js` (이전 버전)
- **역할**: 병렬 처리 관리
- **주요 기능**:
  - 여러 사건 동시 처리
  - 작업 큐 관리
  - 결과 수집

### `parallel-cases.test.js`
- **역할**: 병렬 처리 테스트
- **테스트 항목**:
  - 다중 브라우저 실행
  - 병렬 처리 성능
  - 에러 핸들링

### `single-case.test.js`
- **역할**: 단일 사건 처리 테스트
- **테스트 항목**:
  - 사건 검색
  - 캡차 처리
  - 데이터 추출
