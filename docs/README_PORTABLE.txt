================================================================================
  case-ing 포터블 버전 — 사용 안내 (README)
================================================================================

대법원 「나의 사건 검색」을 자동으로 조회하는 프로그램입니다.
Python·Node를 따로 설치할 필요 없습니다. 이 폴더만 있으면 됩니다.

- 개발자 : 박지원 -
--------------------------------------------------------------------------------
1. 준비
--------------------------------------------------------------------------------

  1) zip을 받은 경우, 원하는 위치에 압축을 완전히 해제합니다.

  2) 폴더 안에 아래가 있는지 확인합니다.
     - CaseIng.exe
     - runtime\  (node, puppeteer/chrome)
     - src\
     - node_modules\
     - api\certification\


--------------------------------------------------------------------------------
2. 구글 연동 파일(client_secret.json) 넣기 (최초 1회)
--------------------------------------------------------------------------------

  ■ client_secret.json 이 무엇인가요?
    - 이 프로그램이 "내 구글 계정으로 로그인해서 구글 시트에 저장해도
      될까요?" 하고 구글에 물어볼 때 쓰는 열쇠 파일입니다.
    - 구글이 정식으로 발급해 주는 파일이며, 이게 있어야 구글 시트/
      캘린더 연동이 됩니다.
    - 파일 하나로 여러 사람이 함께 쓸 수 있습니다.


  ■ 방법 A. 배포자에게서 파일을 받은 경우 (가장 쉬움)
  --------------------------------------------------

    1) 받은 파일 이름이 client_secret.json 이 맞는지 확인합니다.
       (이름이 다르면 client_secret.json 으로 바꿉니다.)

    2) 이 폴더 안 api\certification\ 폴더를 엽니다.
       전체 경로 예)
       C:\Apps\case-ing-portable\api\certification\

    3) 그 폴더 안에 client_secret.json 을 붙여넣습니다.
       (api\certification\client_secret.json 형태가 되어야 함)

    → 방법 A가 끝나면 아래 "■ 공통: 프로그램에서 로그인"으로 갑니다.


  ■ 방법 B. 직접 발급받는 경우 (배포자가 없을 때)
  --------------------------------------------------

    구글 클라우드 콘솔에서 무료로 발급받습니다.
    (구글 계정만 있으면 됩니다.)

    1) 브라우저에서 아래 주소로 들어가 로그인합니다.
       https://console.cloud.google.com/

    2) 상단의 프로젝트 선택 → "새 프로젝트"로 프로젝트를 하나
       만듭니다. (이름은 자유, 예: case-ing)
       이미 프로젝트가 있으면 그걸 선택해도 됩니다.

    3) 왼쪽 메뉴에서 "API 및 서비스" → "라이브러리"로 이동해
       아래 두 개를 검색해서 각각 "사용 설정"을 누릅니다.
         - Google Sheets API
         - Google Drive API
       (구글 캘린더도 쓸 거라면 Google Calendar API 도 사용 설정)

    4) "API 및 서비스" → "OAuth 동의 화면"으로 이동합니다.
         - User Type: "외부(External)" 선택 후 만들기
         - 앱 이름/이메일 등 필수 항목만 대충 채우고 저장
         - "테스트 사용자"에 본인 구글 이메일을 추가합니다.
           (여기에 추가된 계정만 로그인할 수 있습니다.)

    5) "API 및 서비스" → "사용자 인증 정보"로 이동합니다.
         - 상단 "+ 사용자 인증 정보 만들기"
         - "OAuth 클라이언트 ID" 선택
         - 애플리케이션 유형: "데스크톱 앱" 선택
         - 만들기 → JSON 다운로드 버튼으로 파일을 내려받습니다.

    6) 내려받은 파일 이름을 client_secret.json 으로 바꿉니다.
       (원래 이름은 client_secret_xxxx.json 처럼 길게 되어 있음)

    7) 이 폴더 안 api\certification\ 폴더에 넣습니다.
       (api\certification\client_secret.json 형태)


  ■ 공통: 프로그램에서 로그인
  --------------------------------------------------

    1) CaseIng.exe 를 실행합니다.

    2) 프로그램 「설정」에서 구글 계정 연동(로그인)을 한 번 합니다.
       - 브라우저가 열리면 구글 계정으로 로그인합니다.
       - "이 앱은 Google에서 확인하지 않았습니다" 경고가 나오면
         "고급" → "(안전하지 않음)이동" 을 눌러 계속 진행합니다.
         (본인이 만든 앱이므로 안전합니다.)
       - 접근 권한 요청이 나오면 "허용"을 누릅니다.

    3) 로그인에 성공하면
       data\google_user_token.json 이 자동으로 생깁니다.
       (다음부터는 다시 로그인하지 않아도 됩니다.)

    4) 다음 "3. 구글 시트 준비 및 연결"로 넘어갑니다.


  ■ 주의사항
  --------------------------------------------------
    - client_secret.json 은 비밀번호와 같습니다.
      아무 곳에나 올리거나 모르는 사람에게 주지 마세요.
    - 파일 위치는 반드시 api\certification\ 폴더 안이어야 합니다.
    - 파일이 없거나 위치가 틀리면 "시트 연동 실패" 오류가 납니다.


--------------------------------------------------------------------------------
3. 구글 시트 준비 및 연결 (최초 1회)
--------------------------------------------------------------------------------

  이 프로그램은 조회한 사건 진행 내용을 "구글 스프레드시트"에
  저장합니다. 그래서 저장할 시트를 미리 하나 준비해 두어야 합니다.


  ■ 3-1. 스프레드시트 만들기
  --------------------------------------------------

    1) 브라우저에서 https://sheets.google.com 에 접속합니다.
       (2번에서 로그인한 것과 같은 구글 계정을 쓰는 것이 가장 쉽습니다.)

    2) "빈 스프레드시트"를 눌러 새 시트를 만듭니다.
       이름은 자유입니다. (예: case-ing)


  ■ 3-2. "사건 목록" 탭(워크시트) 만들기
  --------------------------------------------------

    1) 스프레드시트 왼쪽 아래의 탭 이름을 "사건 목록" 으로 바꿉니다.
       (프로그램 설정의 "사건 목록 시트 이름"과 글자가 똑같아야 합니다.
        기본값이 "사건 목록" 입니다.)

    2) 첫 번째 줄(1행)에 아래 제목들을 순서대로 입력합니다.
         법원    사건번호    피고    사건명    비고

    ※ 사건 자체는 프로그램의 "사건목록 관리" 기능으로 추가해도 됩니다.
       그래도 위 제목 행은 있는 것이 좋습니다.


  ■ 3-3. 시트 ID 복사하기
  --------------------------------------------------

    스프레드시트를 연 상태에서 브라우저 주소창을 봅니다.

      https://docs.google.com/spreadsheets/d/【이 부분이 시트 ID】/edit

    /d/ 와 /edit 사이의 긴 문자열이 "스프레드시트 ID" 입니다.
    이 부분을 드래그해서 복사해 둡니다.
    (예: 1ShaDTz4pj8SRWvf3ahcVI-gStYK-dFSBPsS6BnDOFzU)


  ■ 3-4. 시트 공유 권한 (매우 중요)
  --------------------------------------------------

    2번에서 로그인한 구글 계정이 이 시트를 "편집"할 수 있어야
    저장이 됩니다.

    - 본인 계정으로 직접 만든 시트라면 → 그대로 OK.

    - 다른 사람이 만든 시트를 쓴다면 → 그 시트에서
      오른쪽 위 [공유] 버튼 → 내 구글 이메일을 "편집자"로 추가.

    권한이 없으면 "시트 연동 실패" 또는 저장 오류가 납니다.


  ■ 3-5. 프로그램 설정에 입력하기
  --------------------------------------------------

    1) CaseIng.exe 실행 → 「설정」 → "구글 시트" 탭을 엽니다.

    2) 아래 칸을 채웁니다.
         - 스프레드시트 ID   : 3-3에서 복사한 ID
         - 스프레드시트 이름 : 3-1에서 만든 시트 이름
         - 사건 목록 시트 이름 : 사건 목록  (기본값 그대로면 됨)

    3) [저장]을 누릅니다.

    → 이제 사건을 조회하면 이 시트에 자동으로 기록됩니다.


--------------------------------------------------------------------------------
4. 실행 방법
--------------------------------------------------------------------------------

  1) CaseIng.exe 를 더블클릭합니다.

  2) 사건 목록이 보이면 정상입니다.

  3) 사건 조회를 시작하면 캡차(자동입력방지 숫자) 화면이 뜹니다.
     OCR이 숫자를 읽고 자동으로 입력을 시도합니다.


--------------------------------------------------------------------------------
5. 캡차(OCR) 상태 문구
--------------------------------------------------------------------------------

  OCR 인식 중      … 숫자를 읽는 중 (입력칸이 잠시 잠깁니다)
  OCR 자동입력중   … 숫자를 채웠고, 곧 자동으로 완료합니다
  수동입력 필요    … OCR 실패 — 직접 입력한 뒤 「캡차 입력 완료」를 누르세요


--------------------------------------------------------------------------------
6. 첫 실행·용량 안내
--------------------------------------------------------------------------------

  - 첫 실행 시 OCR 모델 준비로 수십 초~수분 걸릴 수 있습니다.
    인터넷 연결이 필요할 수 있습니다.

  - Tesseract는 필수가 아닙니다. EasyOCR만으로도 동작합니다.

  - 폴더 용량은 약 1.5GB 전후입니다.
    (브라우저 자동화 + OCR 포함)


--------------------------------------------------------------------------------
7. 문제 해결
--------------------------------------------------------------------------------

  [프로그램이 안 켜질 때]
    - zip을 완전히 해제했는지 확인
    - Windows Defender / 백신 차단 여부 확인
    - CaseIng.exe 가 폴더 맨 위에 있는지 확인

  [캡차·브라우저 오류]
    - runtime\node\node.exe 존재 여부
    - runtime\puppeteer\chrome\ 폴더 존재 여부
    - src\, node_modules\ 존재 여부

  [구글 시트 오류]
    - api\certification\client_secret.json 있는지
    - 설정에서 구글 로그인 했는지
    - 설정의 스프레드시트 ID가 정확한지 (3-3 참고)
    - "사건 목록" 탭 이름이 설정값과 똑같은지 (3-2 참고)
    - 로그인한 계정에 그 시트의 편집 권한이 있는지 (3-4 참고)

  [OCR 실패]
    - 「수동입력 필요」가 뜨면 숫자를 직접 입력 후 완료


--------------------------------------------------------------------------------
8. 폴더를 옮기거나 백업할 때
--------------------------------------------------------------------------------

  - 이 폴더 전체를 통째로 복사하면 다른 PC에서도 사용할 수 있습니다.
  - 다만 client_secret.json 과 data\ 안의 토큰은 개인 정보이므로
    신뢰할 수 있는 사람에게만 전달하세요.
  - 다른 PC에서는 설정에서 구글 로그인을 다시 해야 할 수 있습니다.
