# 미어캣싱 README (v5.3.0)

대법원 나의 사건 조회 자동화 시스템 (Puppeteer + Python GUI) - v5.3.0  
제품 UI 명칭: **미어캣싱** (저장소/폴더명 case-ing 유지)

공식 버전: **v5.2.0 → v5.3.0**

## 이 버전에서 달라진 점 (요약)

1. **WORKER_IDLE 가짜 실패 수정** — 이전 사건 잔여 IDLE로 다음 건이 연쇄 실패하던 문제를 고쳤습니다.
2. **스마트 스킵 복구** — 검색 UI 대기·느슨한 번호 매칭·about:blank 제거로, 한 번 조회한 사건은 캡차 없이 진행합니다.
3. **종국 판별 정확화** — 기본내용「종국결과」칸만 봅니다. 이름(박종국) 오탐을 막습니다.
4. **CLI 설정 로드** — 자동조회(`--auto`)도 `user_settings.json`의 수신 메일을 읽습니다.
5. **taskkill 창 숨김** — 조회 시작 시 Windows CMD 번쩍임을 줄였습니다.
6. **사고 기록** — `99.Error case/`에 2026-09-09 사례를 남겼습니다.

## 실행

```bash
python main.py
python main.py --auto
```

## 설정 팁

- **브라우저 프로필 수**: 설정 → 사건 조회 설정. 프로필당 사건 40건 이하 권장.
- **알림 메일**: 설정 → 알림 수신 메일 주소. GUI·CLI 모두 같은 `user_settings.json`을 씁니다.
- 프로필 수를 바꾸면 첫 한 바퀴는 캡차가 필요할 수 있고, 같은 프로필에서 저장한 건부터 스마트 스킵이 됩니다.

사용법·설치·FAQ는 루트 [`README.md`](../README.md)에 자세히 적어 두었습니다.
