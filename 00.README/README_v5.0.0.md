# 미어캣싱 README (v5.0.0)

대법원 나의 사건 조회 자동화 시스템 (Puppeteer + Python GUI) - v5.0.0  
제품 UI 명칭: **미어캣싱** (저장소/폴더명 case-ing 유지)

공식 버전: **v4.12.1 → v5.0.0**

## 이 버전에서 달라진 점 (요약)

1. 기일 달력·지연 등록 비고·미어캣싱 제품명
2. 설정 창「사건 조회 설정」/「테마」, 적용·확인·취소
3. 진행상황 Canvas 워터마크·스크롤·드래그 선택
4. OCR 자동 제출 수정, 감정기일 스타일 통일
5. 기간조회·시트 관리·버전 확인 등 4.12.1 이후 누적 기능

## 실행

```bash
python main.py
python main.py --auto
```
