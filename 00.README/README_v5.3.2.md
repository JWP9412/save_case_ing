# 미어캣싱 README (v5.3.2)

대법원 나의 사건 조회 자동화 시스템 (Puppeteer + Python GUI) - v5.3.2  
제품 UI 명칭: **미어캣싱** (저장소/폴더명 case-ing 유지)

공식 버전: **v5.3.1 → v5.3.2**

## 이 버전에서 달라진 점 (요약)

1. **한번에 여러 사건 추가** — 사건목록 관리에서 엑셀형 격자로 여러 건을 붙여 넣거나 입력할 수 있습니다.
2. **법원 드롭다운·지우기** — 일괄 격자 법원 열 자동완성, 선택 행/전체 지우기.
3. **일괄 창 크래시 수정** — 창이 떴다 꺼지거나 메인까지 죽던 문제를 고쳤습니다.
4. **당사자내용 표시·파싱** — 이름 열 잘림·표 파싱(rowspan/여러 줄) 보강. (캐시는 재조회 시 갱신)
5. **일반내용 창 가독성** — 최소 크기·줄바꿈·기본내용 열 균등·기일/당사자 표별 열 비중.

## 실행

```bash
python main.py
python main.py --auto
```

## 설정 팁

- **일괄 추가**: 사건목록 관리 → 「한번에 여러 사건 추가하기」. 엑셀 4열(법원·사건번호·피고·사건명) 복사 후 Ctrl+V.
- **당사자 이름**: 예전 조회 캐시가 짧으면 일반내용 창의 「당사자·대리인 내용 변경시 클릭」으로 재조회.
- **숨긴 사건**: 사건목록 관리에서 숨기면 GUI·CLI 모두 조회 대상에서 빠집니다.

사용법·설치·FAQ는 루트 [`README.md`](../README.md)에 자세히 적어 두었습니다.
