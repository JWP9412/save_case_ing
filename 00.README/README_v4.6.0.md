# README v4.6.0

## 주요 변경 사항

### 1. 사건목록 관리 다이얼로그 (v4.6.0)
- **적용·확인·취소**: 적용 시 스냅샷 저장, 취소 시 "적용 사항을 취소하시겠습니까?" 확인 후 되돌리기, 확인 시 적용+시트 새로고침+닫기. X 버튼 = 취소 동작.
- **버튼 상태**: 숨기기, 숨김 해제, 사건 삭제, 변경 취소, 추가, 선택 사건 불러오기, 저장 버튼을 선택/폼 상태에 따라 활성·비활성.

### 2. 사건목록 관리 (v4.5.0)
- 사건 추가/수정/삭제/숨기기/숨김 해제 다이얼로그. 법원 드롭다운·자동완성. 구글 시트 행 추가/수정/삭제, 숨긴 사건 로컬 관리.

### 3. 사건 목록 UI 개선 (v4.4.6)
- 기일 열 디데이·민트색·YY.MM.DD, 최근 업데이트 수직 정렬, 행 높이 90px, 시트 버튼 아이콘만 등.

### 4. 기타
- 열 개수 11. sort_manager 정렬 열 3(기일), 4(비고), 8, 9(최근 업데이트).
