# README v4.4.6

## 주요 변경 사항

### 1. 사건 목록 UI 개선 (v4.4.6)
- **기일 열**: 디데이(D+/D-) 표시, 변론/판결선고기일 민트색, 날짜 2자리 연도(YY.MM.DD), CTkTextbox로 드래그 복사 가능, 수직 가운데 정렬.
- **최근 업데이트 열**: 날짜 `26.03.11.` 형식 + 시간 줄바꿈, grid로 수직 가운데 정렬.
- **법원/사건번호·피고/사건명**: 줄바꿈, 수직·수평 가운데(비고 제외). 비고는 좌측 정렬.
- **행 높이 90px**, grid+스페이서로 모든 데이터 셀 수직 가운데 정렬.
- **시트 버튼**: "시트" 텍스트 제거, 아이콘만 표시.

### 2. 사건 목록 '기일' 열 (v4.4.0)
- 구글 시트 개별 시트(일자·내용)에서 변론기일/판결선고기일과 날짜·시간을 파싱해 '기일' 열에 표시 (캐시 기반).

### 3. 정렬 및 인덱스
- sort_manager: 정렬 기준 열 인덱스 3=기일, 4=비고, 8=자동 조회, 9=최근 업데이트.
- AppController: 기본 정렬 열 최근 업데이트(인덱스 9).

### 4. 기타
- 열 개수 11. column_widths.json/column_order.json 길이 불일치 시 기본값 사용.
