# 미어캣싱 README (v4.14.1)

대법원 나의 사건 조회 자동화 시스템 (Puppeteer + Python GUI) - v4.14.1  
제품 UI 명칭: **미어캣싱** (저장소/폴더명 case-ing 유지)

## 이 버전에서 달라진 점

1. **hearing_info 폴백** — 재조회 전에도 목록 기일이 달력에 표시됨.
2. **칸 안 요약** — `• 이름 변론`처럼 날짜를 누르지 않아도 보임.
3. **버튼 위치** — 사건목록 관리 왼쪽의 「📅 기일 달력」.

## 실행

```bash
python main.py
python main.py --auto
```
