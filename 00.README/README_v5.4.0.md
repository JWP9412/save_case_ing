# 미어캣싱 README (v5.4.0)

대법원 나의 사건 조회 자동화 시스템 (Puppeteer + Python GUI) - v5.4.0  
제품 UI 명칭: **미어캣싱** (저장소/폴더명 case-ing 유지)

공식 버전: **v5.3.3 → v5.4.0**

## 이 버전에서 달라진 점 (요약)

1. **알림메일 카드형 디자인** — 사건별 카드, 시트 글자색 유지.
2. **긴 본문 분할 발송** — 시트 셀 한도를 넘으면 여러 메일로 나눠 보냄. 조회 요약은 마지막 통.
3. **잘림 안내 정리** — 깨진 HTML 태그 대신 생략 문구만 표시.

## 실행

```bash
python main.py
python main.py --auto
```
