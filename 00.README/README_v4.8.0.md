# README v4.8.0

## 주요 변경 사항

### 1. 구글 시트 429(할당량 초과) 완화 (v4.8.0)
- **저장 직렬화**: 여러 사건이 동시에 시트를 두드리지 않도록, 읽기→저장→검증을 한 번에 한 사건만 수행.
- **읽기 1회**: 사건당 시트 전체를 한 번만 읽고, 신규 건수·덮어쓰기·검증에 재사용.
- **서식 1회 전송**: 색상·정렬·열 너비를 한 번의 API 호출로 처리.
- **재시도 개선**: 429 발생 시 대기 시간을 점점 늘리고, 무작위 흔들기(jitter)로 동시 재시도 충돌 완화.

### 2. 신규 건수·알림메일 버그 수정 (v4.8.0)
- 시트 조회 실패 시 `+375건`처럼 **전부 신규로 오판**하던 문제 수정.
- 알림메일 본문이 **50,000자**를 넘으면 잘라 저장(저장 실패 방지).

### 3. 구글 캘린더·OAuth·시트·메일 (v4.7.0)
- **캘린더**: 변론·감정·판결 기일을 설정에서 켠 경우에만 구글 캘린더에 자동 등록.
- **OAuth**: 시트·캘린더 동일 계정, 프로그램 설정에서 연동.
- **시트 열 밀림 수정**: 진행내용이 A~F열에만 저장되도록 수정.
- **메일 바로가기**: 알림 메일에서 해당 사건 시트로 바로 이동하는 링크.

### 4. 기록 초기화·재수집·중복 제거 (v4.7.0)
- **초기화·재수집**: 시트·로컬 기록 삭제 후 대법원에서 처음부터 다시 수집.
- **중복 오류 제거**: 대법원 실제 기록과 맞춰 잘못 쌓인 행만 정리.
