# README v4.6.2

## 주요 변경 사항

### 1. 사건 목록 캐시 및 시작 UX (v4.6.2)
- **캐시**: 시작 시 `data/case_list_cache.json` 우선 로드. 새로고침 버튼·다이얼로그 확인 시에만 구글 시트 조회 후 캐시 저장. 경로는 프로젝트 루트 기준.
- **시작 시 목록 표시**: 캐시 있을 때 창 숨긴 채 목록 그린 뒤 표시해 열리자마자 항목 표시.
- **UI 배치**: 30건 이하 한 번에 그리기.
- **F5**: 새로고침 단축키 F5, 버튼 텍스트 "새로고침 (F5)".

### 2. 사건목록 관리 다이얼로그 (v4.6.0)
- 적용·확인·취소 플로우, 7개 버튼 선택/폼 상태에 따른 활성·비활성.

### 3. 사건목록 관리 (v4.5.0)
- 사건 추가/수정/삭제/숨기기/숨김 해제 다이얼로그. 법원 드롭다운·자동완성. 구글 시트 행 추가/수정/삭제, 숨긴 사건 로컬 관리.

### 4. 사건 목록 UI 개선 (v4.4.6)
- 기일 열 디데이·민트색·YY.MM.DD, 최근 업데이트 수직 정렬, 행 높이 90px, 시트 버튼 아이콘만 등.

### 5. 기타
- 열 개수 11. sort_manager 정렬 열 3(기일), 4(비고), 8, 9(최근 업데이트).
