# case-ing README (v4.10.0)

대법원 나의 사건 조회 자동화 시스템 (Puppeteer + Python GUI) - v4.10.0

## 이 버전에서 달라진 점

1. **제어 패널 UI**
   - 깨지던 이모지 제거, `▶ 사건 기록 수집 실행`으로 시작 버튼 변경.
   - `특정 기간 조회`, `시트-대법원 대조` 버튼 추가.

2. **알림메일 요약**
   - 여러 번 나눠 조회해도 결과가 누적되며, 사건 목록 전체(미조회 포함)가 하단에 표시됩니다.
   - `--auto` 실행 결과도 같은 누적 파일에 남아 GUI 메일에 포함됩니다.

3. **특정 기간 조회**
   - 날짜를 지정해 그 기간의 대법원 기록만 모아 미리보고 메일로 보낼 수 있습니다.
   - 구글 시트·기존 조회 이력에는 저장하지 않습니다.
   - 각 행이 시트에 이미 있는지(있음/유사/없음) 함께 표시합니다.

4. **시트-대법원 대조**
   - 시트에 저장된 진행내용과 대법원 현재 기록이 내용까지 일치하는지 비교합니다.

## 실행

```bash
python main.py
python main.py --auto
```

상세 구조·이력은 루트 `README.md` 및 `00.*` 문서를 참고하세요.
