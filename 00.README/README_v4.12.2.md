# case-ing README (v4.12.2)

대법원 나의 사건 조회 자동화 시스템 (Puppeteer + Python GUI) - v4.12.2

## 이 버전에서 달라진 점

1. **사건 시트 관리 드롭다운** — 중복 제거·초기화 재수집·시트 대조를 한 메뉴로 묶음.
2. **버전 업데이트 확인** — GitHub 최신 릴리스와 현재 앱 버전 비교.
3. **일반내용 표 정렬** — 헤더와 내용 열이 맞게 표시.

## 실행

```bash
python main.py
python main.py --auto
```

또는 프로젝트 루트 `실행.bat` / `CaseIng.lnk`.

상세 구조·이력은 루트 `README.md` 및 `00.*` 문서를 참고하세요.
