# README v4.4.0

## 주요 변경 사항

### 1. 사건 목록 '기일' 열 추가 (v4.4.0)
- **구글 시트 연동**: A열 `일자`, B열 기일 정보(예: `판결선고기일(동관 제557호 법정... 14:00)`)를 읽어와 사건 목록에 '기일' 열로 표시.
- **파싱**: `gui/panels/case_row.py`의 `_extract_hearing_text()`에서 정규식으로 `변론기일`/`판결선고기일`과 시간을 추출하고, `기일 날짜 시간` 형식으로 렌더링.
- **설정**: `config.py`의 `COL_NAMES`, `COL_WIDTHS`, `DEFAULT_COL_ORDER`를 확장해 '피고/사건명' 우측에 '기일' 열(내부 인덱스 3) 배치.

### 2. 정렬 및 인덱스 정리
- **sort_manager**: 정렬 기준 열 인덱스 조정 (3=기일, 4=비고, 8=자동 조회, 9=최근 업데이트).
- **헤더 클릭**: 기일·비고·자동 조회·최근 업데이트 열에서 정렬 가능.
- **AppController**: 기본 정렬 열을 최근 업데이트(인덱스 9)로 설정.

### 3. 기타
- 열 개수 10 → 11로 변경. 기존 `column_widths.json`/`column_order.json`은 길이 불일치 시 기본값 사용.

## Technical Updates
