# README v4.3.0 (2026-03-08)

## 주요 변경 사항

### 1. CLI 자동 실행 모드 안정화 (`--auto`)
- **수동 실행과 동일한 2단계 프로세스 적용**: 사이트 먼저 접속(브라우저 기동) 후 클릭 명령을 전송하여 즉시 실패하던 문제를 완벽하게 해결했습니다.
- **다중 프로필 락(Profile Lock) 지원**: CLI 모드에서도 여러 개의 브라우저를 동시에 안전하게 띄워 작업할 수 있습니다.

### 2. 이메일 조회 결과 리포트 디자인 개편
- **한눈에 들어오는 요약 표**: 하단에 쉼표로 나열되던 사건번호들을 이제 깔끔한 표로 볼 수 있습니다.
- **[사건번호 | 피고/사건명] 구조**: 어떤 사건이 성공하고 실패했는지 이메일에서 즉시 확인 가능합니다.
- **상태별 그룹화**: 성공, 변경없음, 실패, 캡차 재시도 대기 등으로 나뉘어 명확한 결과를 전달합니다.

### 3. 안정성 및 클린업 강화
- 자동 실행 완료 후 브라우저 프로세스를 더 확실하게 정리하여 시스템 자원을 관리합니다.
