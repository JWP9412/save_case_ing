# 미어캣싱 README (v5.1.0)

대법원 나의 사건 조회 자동화 시스템 (Puppeteer + Python GUI) - v5.1.0  
제품 UI 명칭: **미어캣싱** (저장소/폴더명 case-ing 유지)

공식 버전: **v5.0.0 → v5.1.0**

## 이 버전에서 달라진 점 (요약)

1. **알림메일** — 송달「결과」만 바뀐 행을「결과 변경 내역」으로 따로 표시 (8월 행이 9월에 또「신규」로 뜨던 문제 해결).
2. **시트 보호** — 조회 실패를 0건 정상으로 오인해 진행내용이 지워지던 사고 재발 방지 (3중 가드 + `99.Error case` 문서).
3. **캡차·OCR** — 수동 창 화면 밖 표시 수정, 중지 후 자동 제출 차단, 스마트 스킵 실패 시 정규 캡차 폴백.
4. **코드 구조** — `ProcessController`를 역할별 패키지로 분리 (import 경로는 동일).

## 실행

```bash
python main.py
python main.py --auto
```
