# 미어캣싱 README (v5.2.0)

대법원 나의 사건 조회 자동화 시스템 (Puppeteer + Python GUI) - v5.2.0  
제품 UI 명칭: **미어캣싱** (저장소/폴더명 case-ing 유지)

공식 버전: **v5.1.1 → v5.2.0**

## 이 버전에서 달라진 점 (요약)

1. **실패 집계 수정** — 여러 파도로 나뉜 배치에서도 실패 건수가 맞게 집계됩니다.
2. **진행내용 탭/그리드 안정화** — 탭 클릭을 실제 전환으로 검증하고, 실패 시 브라우저를 다시 띄워 재시도합니다.
3. **OCR 신뢰도** — Tesseract가 길이만 맞으면 1.00을 주던 문제를 고쳐, 오독 자동 제출을 줄입니다.
4. **Chrome 재사용** — 레인(프로필)당 브라우저 1개를 유지해 기동·메모리를 줄입니다. 설정에서 프로필 수를 조절할 수 있습니다.
5. **속도·메모리** — EasyOCR 사전 로딩, 리소스 차단, 캐시/스크린샷 정리, OCR 유휴 언로드.
6. **캡차 학습 데이터** — 성공/실패 캡차를 `data/captcha_dataset/`에 자동 수집합니다.

## 실행

```bash
python main.py
python main.py --auto
```

## 설정 팁

- **브라우저 프로필 수**: 설정 → 사건 조회 설정. 프로필당 사건 40건 이하 권장 (대법원 최근 검색 한도 약 50건).
- 프로필 수를 바꾸면 첫 한 바퀴는 캡차를 다시 풀어야 하고, 두 번째부터 스마트 스킵이 회복됩니다.

사용법·설치·FAQ는 루트 [`README.md`](../README.md)에 자세히 적어 두었습니다.
