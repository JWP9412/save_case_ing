# case-ing README (v4.12.0)

대법원 나의 사건 조회 자동화 시스템 (Puppeteer + Python GUI) - v4.12.0

## 이 버전에서 달라진 점

1. **일반내용 돋보기 뷰어**
   - 평소 사건 조회 때 대법원 '일반내용'(기본내용·기일·제출서류·당사자·대리인)을 함께 저장.
   - 사건 목록 '피고/사건명' 칸의 보기 버튼으로 새 창에서 확인.
   - 당사자·대리인은 창 안 버튼으로 필요할 때만 재조회.

2. **v4.11.0에서 이어진 기능**
   - 앱 아이콘(미어캣+저울), 특정 기간 조회, 시트-대법원 대조, 메일 요약 누적.

## 실행

```bash
python main.py
python main.py --auto
```

또는 프로젝트 루트 `실행.bat` / `CaseIng.lnk`.

상세 구조·이력은 루트 `README.md` 및 `00.*` 문서를 참고하세요.
