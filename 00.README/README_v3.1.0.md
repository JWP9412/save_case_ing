# case-ing

대법원 나의 사건 조회 자동화 시스템 (Puppeteer + Python GUI)

## 📚 원본 출처

이 프로젝트는 [iicdii/case-ing](https://github.com/iicdii/case-ing)를 기반으로 하여 **Puppeteer 기반 병렬 처리** 및 **Python GUI 일괄 처리 시스템**으로 전환한 포크 버전입니다.

**원본 저장소**: https://github.com/iicdii/case-ing  
**포크 저장소**: https://github.com/JWP9412/save_case_ing

<a href="https://github.com/iicdii/case-ing/blob/master/LICENSE" alt="License">
    <img src="https://img.shields.io/badge/License-MIT-yellow.svg" />
</a>

case-ing는 case + ~ing의 합성어로 여러개의 사건 진행현황을 쉽게 조회하도록 도와주는 자동화 도구입니다.

## 🎯 현재 버전 특징 (v3.1.0)

### ✨ 주요 기능

1. **대화형 러너 (Interactive Runner) & 단일 지속 프로세스**
   - 브라우저를 껐다 켜거나 재연결하는 방식 대신, **하나의 프로세스가 계속 실행**되는 구조로 변경하여 안정성을 극대화했습니다.
   - **캡차 이미지 유지**: 브라우저 세션이 끊기지 않으므로, 캡차 캡처 후 입력 단계까지 이미지가 절대 바뀌지 않습니다.
   - **소켓 연결 오류 해결**: 메모리 관리 옵션 최적화로 브라우저 비정상 종료를 방지합니다.

2. **스마트 스킵 (Smart Skip)**
   - **'CLICK' 입력 지원**: 캡차 입력란에 'CLICK'을 입력(또는 자동 입력)하면 캡차 입력을 건너뛰고 최근 검색 기록을 클릭하여 빠르게 조회합니다.
   - **쿠키 지속성**: 브라우저 세션과 쿠키를 유지하여 재검색 시 불필요한 입력을 최소화합니다.

3. **향상된 데이터 추출 및 자동화**
   - **강력한 탭/그리드 탐색**: ID 변경에 대응하는 텍스트 기반 검색과 이중 전략(Dual Strategy)으로 '진행내용' 탭을 확실하게 찾아냅니다.
   - **입력 오류 방지**: 사건번호와 당사자명 입력 시 재클릭 및 포커스 로직을 추가하여 WebSquare 프레임워크의 인식 오류를 해결했습니다.
   - **페이지 새로고침 방지**: 검색 버튼 클릭 로직을 개선하여 불필요한 페이지 리로드를 막았습니다.

4. **Python GUI 일괄 처리 시스템**
   - 구글 시트에서 사건 목록 자동 로드
   - 여러 사건을 동시에 처리 (병렬 처리)
   - 캡차 이미지 자동 캡처 및 수동 입력
   - 진행내용 자동 추출 및 구글 시트 저장

5. **구글 시트 연동**
   - 사건 목록 자동 읽기
   - 진행내용 자동 저장
   - 워크시트 자동 생성 (피고_비고_사건번호_법원)
   - 업데이트 일시 및 이전 업데이트 기록

## 🚀 빠른 시작

### 1. 사전 준비

#### 필수 소프트웨어
- **Node.js** >= 14
- **Python** >= 3.7
- **npm** (Node.js와 함께 설치됨)

#### 의존성 설치

```bash
# Node.js 패키지 설치
npm install

# Python 패키지 설치
pip install -r requirements.txt
```

### 2. 구글 시트 설정

#### 2.1. 구글 스프레드시트 생성

두 개의 워크시트가 필요합니다:

**① 사건 목록 시트**
- 헤더: 사건번호, 피고, 법원, 비고
- 처리할 사건 목록 입력

**② 진행내용 시트**
- 자동으로 생성됨
- 시트명: `{피고}_{비고}_{사건번호}_{법원}`

#### 2.2. 서비스 계정 설정

자세한 설정 방법은 [`api/certification/GOOGLE_AUTH_SETUP.md`](api/certification/GOOGLE_AUTH_SETUP.md) 참조

1. 구글 클라우드 콘솔에서 서비스 계정 생성
2. JSON 키 다운로드
3. `api/certification/service-account.json`으로 저장
4. 스프레드시트에 서비스 계정 이메일 추가 (편집자 권한)

#### 2.3. 스프레드시트 ID 설정

`batch_gui_maker.py`에서 스프레드시트 ID 확인:
```python
spreadsheet_id = '1ShaDTz4pj8SRWvf3ahcVI-gStYK-dFSBPsS6BnDOFzU'
```

### 3. 프로그램 실행

```bash
# 메인 GUI 프로그램 실행
python batch_gui_maker.py
```

## 📖 사용 방법

### 1️⃣ 구글 시트 로드

1. GUI 실행 후 **"구글 시트 로드"** 버튼 클릭
2. 구글 시트에서 사건 목록 자동 로드
3. 사건 목록이 화면에 표시됨

### 2️⃣ 처리할 사건 선택

- 각 사건의 **체크박스**를 선택
- 여러 사건을 동시에 선택 가능

### 3️⃣ 처리 설정

- **병렬 처리 수**: 동시에 처리할 사건 개수 (1~10)
- **캡차 재시도 횟수**: 캡차 오류 시 재시도 횟수
- **재시도 간 대기시간**: 재시도 사이 대기 시간 (초)

### 4️⃣ 캡차 이미지 로드

1. **"캡차 이미지 로드"** 버튼 클릭
2. 선택한 사건들의 캡차 이미지가 자동으로 캡처됨
3. 각 사건의 캡차 이미지가 화면에 표시됨

### 5️⃣ 캡차 입력

1. 각 캡차 이미지를 보고 6자리 숫자 입력
2. **Enter 키**를 누르면 다음 입력칸으로 자동 이동
3. 모든 캡차 입력 완료 후 **"캡차 입력 완료"** 버튼 클릭

### 6️⃣ 자동 처리

1. 입력한 캡차로 자동 검색 실행
2. 진행내용 데이터 자동 추출
3. 구글 시트에 자동 저장
4. 처리 완료 후 상태 업데이트

## 🎨 GUI 기능 설명

### 제어 패널

#### 버튼
- **🗂️ 구글 시트 로드**: 구글 시트에서 사건 목록 가져오기
- **📋 전체 선택**: 모든 사건 선택
- **❌ 전체 해제**: 모든 선택 해제
- **🖼️ 캡차 이미지 로드**: 선택한 사건의 캡차 이미지 캡처
- **✅ 캡차 입력 완료**: 캡차 입력 후 처리 시작
- **🗑️ 처리 취소**: 진행 중인 처리 중지

#### 처리 설정
- **병렬 처리 수** (3개): 동시에 몇 개 사건을 처리할지 설정
- **캡차 재시도 횟수** (3번): 캡차 오류 시 재시도 횟수
- **재시도 간 대기시간** (2초): 재시도 사이 대기 시간

### 사건 목록

각 사건의 정보가 표시됩니다:
- **선택**: 체크박스로 처리할 사건 선택
- **사건번호**: 예) 2023가합10019
- **피고**: 피고명
- **법원**: 담당 법원
- **비고**: 추가 정보
- **캡차 이미지**: 캡처된 캡차 이미지
- **캡차 입력**: 캡차 숫자 입력란
- **상태**: 처리 상태 (대기중/입력대기/처리중/완료)
- **최근 업데이트**: 마지막 업데이트 일시 및 경과일 (D+n)

### 진행상황 패널

실시간 로그가 표시됩니다:
- 사건 처리 진행상황
- 캡차 이미지 캡처 상태
- 구글 시트 저장 상태
- 오류 메시지
- 디버그 정보 (필요시)

## 🔧 기술 스택

### Backend (Node.js)
- **Puppeteer**: 브라우저 자동화
- **BrowserManager**: 다중 브라우저 인스턴스 관리
- **ParallelProcessor**: 병렬 처리 로직

### Frontend (Python)
- **Tkinter**: GUI 프레임워크
- **gspread**: 구글 시트 API
- **Pillow (PIL)**: 이미지 처리
- **Threading**: 비동기 처리

### 데이터
- **Google Sheets API**: 사건 목록 및 진행내용 저장
- **JSON**: 로컬 데이터 저장 (결과, 업데이트 기록)

```

   ├─ 기존 브라우저 재연결
   ├─ 캡차 입력
   ├─ 검색 실행
   ├─ 진행내용 탭 클릭

   ├─ 워크시트 생성/열기
   ├─ 진행내용 데이터 저장
   ├─ 업데이트 일시 기록
   └─ 로컬 업데이트 기록 저장
   ↓
7. 완료
```

## 🐛 문제 해결

### GUI 실행 오류

```bash
# Python 버전 확인 (3.7 이상 필요)
python --version

# 패키지 재설치
pip install -r requirements.txt --upgrade
```

### 구글 시트 연결 오류

1. `api/certification/service-account.json` 파일 존재 확인
2. 서비스 계정 이메일이 스프레드시트에 추가되었는지 확인
3. Google Sheets API가 활성화되었는지 확인
4. [`api/certification/GOOGLE_AUTH_SETUP.md`](api/certification/GOOGLE_AUTH_SETUP.md) 참조

### 캡차 이미지가 표시되지 않음

- `screenshots/` 폴더 확인
- 브라우저가 정상적으로 실행되는지 확인
- Node.js 패키지 재설치: `npm install`

### 브라우저가 종료되지 않음

- 수동으로 브라우저 창 닫기
- 또는 GUI에서 "처리 취소" 버튼 클릭
- 작업 관리자에서 Chrome 프로세스 종료

### 진행내용이 저장되지 않음

1. 구글 시트 권한 확인
2. 네트워크 연결 확인
3. 진행상황 로그에서 오류 메시지 확인
