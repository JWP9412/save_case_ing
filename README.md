# case-ing

대법원 나의 사건 조회 자동화 시스템 (Puppeteer + Python GUI) - v4.11.0

- 개발자 : 박지원 -

## 원본 출처

이 프로젝트는 [iicdii/case-ing](https://github.com/iicdii/case-ing)를 기반으로 하여 **Puppeteer 기반 병렬 처리** 및 **Python GUI 일괄 처리 시스템**으로 전환한 포크 버전입니다.

**원본 저장소**: https://github.com/iicdii/case-ing  
**포크 저장소**: https://github.com/JWP9412/save_case_ing

<a href="https://github.com/iicdii/case-ing/blob/master/LICENSE" alt="License">
    <img src="https://img.shields.io/badge/License-MIT-yellow.svg" />
</a>

case-ing는 case + ~ing의 합성어로 여러 개의 사건 진행현황을 쉽게 조회하도록 도와주는 자동화 도구입니다.

---

## 프로젝트 구조

```
case-ing/
├── auto_runner.py               CLI 실행기 (MockApp 인터페이스 통일)
├── config.py                    설정 상수 (APP_VERSION = "4.11.0" 등)
├── main.py                      진입점 (run_app 또는 run_auto_batch)
├── data/                        설정 및 이력용 JSON 통합 폴더
├── ocr_export/                  캡차 OCR (EasyOCR + Tesseract)
├── src/                         Puppeteer 자동화 코드
├── services/                    비즈니스 로직 (OCR, google_oauth, process_controller 등)
├── gui/                         UI (app_controller, panels, dialogs, utils 등)
├── assets/app_icon.ico          앱 아이콘 (창·exe)
├── 실행.bat                     GUI 더블클릭 실행
├── scripts/build_portable.ps1   Windows 포터블 빌드
├── gas/                         GAS 스크립트 (즉시 발송 지원)
└── 00.CHANGELOG, 00.README      버전별 문서
```

## 사용법

### 1. GUI 모드 실행
```bash
python main.py
```

### 2. CLI 자동 실행 모드 (v4.3.0 안정화)
작업 스케줄러 등을 통해 백그라운드에서 주기적으로 조회를 실행할 때 사용합니다.
```bash
python main.py --auto
```

### 3. Windows 포터블 (v4.9.0)
```powershell
powershell -ExecutionPolicy Bypass -File scripts/build_portable.ps1
```
결과 폴더 `case-ing-portable\`의 `CaseIng.exe`를 더블클릭. 안내: `docs/DEPLOY_WINDOWS.md`, 배포용 `README.TXT`.

## 현재 버전 특징 (v4.11.0)

### 주요 개선 사항

1. **앱 아이콘 (미어캣 + 저울)** *(v4.11.0)*
   - 공식 `assets/app_icon.png` / `assets/app_icon.ico`. 창·작업표시줄·`CaseIng.spec` exe 아이콘.
   - `실행.bat`으로 간편 실행. 시작 메뉴/바탕화면은 `CaseIng.lnk`(아이콘 지정) 사용.

2. **특정 기간 조회 · 시트-대법원 대조** *(v4.10.0)*
   - 제어 패널에서 기간(기본 어제~오늘, 달력·자유 형식 입력)을 지정해 해당 기록만 모아 HTML/MD 미리보기·메일 발송.
   - 기간 조회는 시트/기존 조회 이력에 쓰지 않으며, 행별 시트 존재 여부(있음/유사/없음)를 표시.
   - 시트와 대법원 진행내용을 내용 단위로 대조(완전 일치/불일치 요약).

3. **알림메일 요약 누적 · 전체 사건 표기** *(v4.10.0)*
   - 나눠 조회해도 `run_results`에 누적. 미조회 건 포함 전체 목록이 「이번 조회 결과 요약」에 표시.
   - `--auto` 결과도 같은 파일에 남아 GUI 메일에 합류. 자동 실행 갱신 시 새로고침(F5) 안내.

4. **UI 이모지 깨짐 정리** *(v4.10.0)*
   - 맑은 고딕에서 깨지던 이모지 제거. 시작 버튼 `▶ 사건 기록 수집 실행`.

5. **캡차 OCR 자동인식·자동제출** *(v4.9.0)*
   - EasyOCR → Tesseract로 캡차 숫자를 읽고, 신뢰도 통과 시 입력·「캡차 입력 완료」까지 자동.
   - OCR 중 입력칸 잠금, 상태 문구(`OCR 인식 중` / `OCR 자동입력중` / `수동입력 필요`), 실패 시 수동 폴백.

6. **Windows 포터블 배포** *(v4.9.0)*
   - `CaseIng.exe` + 동봉 Node/Chrome/`src`/`ocr_export`. Python·Node 별도 설치 불필요.
   - `BASE_DIR` 상대경로, `.puppeteerrc.cjs`로 Chrome을 `runtime/puppeteer`에 고정.

7. **포터블·인증 사용자 안내 보강** *(v4.9.0)*
   - `client_secret.json` 발급·배치, 구글 시트(사건 목록·시트 ID·편집 권한·설정) 절차를 README에 상세화.

8. **구글 시트 429(할당량 초과) 완화** *(v4.8.0)*
   - 저장(읽기→덮어쓰기→검증)을 **한 번에 한 사건**만 수행해 동시 API 호출 감소.
   - 사건당 시트 **1회 읽기** 스냅샷 재사용, 서식 API **1회** 통합 전송.
   - 429 재시도에 **jitter**·호출 간격 설정, 조회 실패 시 **+N건 오판** 방지, 알림메일 **50,000자** 초과 시 잘림.

9. **구글 캘린더·연동·시트·메일** *(v4.7.0)*
   - 변론·감정·판결 기일을 **설정에서 켠 경우** 구글 캘린더에 자동 등록.
   - 구글 시트·캘린더 **한 번 로그인**으로 연동 (설정창 OAuth).
   - 진행내용이 **G열 이후로 밀리던 버그** 수정.
   - 알림 메일 **바로가기** 링크로 해당 사건 시트 탭 이동.

10. **기록 초기화·재수집·중복 정리** *(v4.7.0)*
   - **「기록 초기화 및 재수집」**: 시트·로컬 기록 삭제 후 대법원에서 처음부터 다시 저장.
   - **「중복 오류 제거」**: 대법원 실제 기록과 맞춰 잘못 쌓인 행만 삭제.

11. **중복 진행내용 버그 수정** *(v4.6.3)*
   - 동일 일자·내용이 여러 행일 때 구글 시트에 반복 저장되던 무한 증식 버그 수정.

12. **사건 목록 캐시 및 시작 UX** *(v4.6.2)*
   - 시작 시 JSON 캐시(`data/case_list_cache.json`) 우선 로드, 새로고침(F5/버튼)·다이얼로그 확인 시에만 구글 시트 조회. 캐시 경로 프로젝트 루트 기준. 캐시 있으면 창 숨긴 채 목록 그린 뒤 표시해 열리자마자 항목 표시. 30건 이하 한 번에 그리기. F5 단축키 및 버튼 "새로고침 (F5)".

13. **사건목록 관리 다이얼로그** *(v4.6.0)*
   - 적용·확인·취소 플로우(적용 스냅샷, 취소 시 확인 후 되돌리기, 확인 시 적용+시트 새로고침+닫기). X 버튼 = 취소. 7개 버튼 선택/폼 상태에 따른 활성·비활성. 람다/리사이저 버그 수정.

14. **사건목록 관리** *(v4.5.0)*
   - 사건 추가/수정/삭제/숨기기/숨김 해제 다이얼로그. 법원 필드 드롭다운·자동완성(오버레이 목록). 사건목록 관리·열 순서 버튼 하늘색·최우측 배치. 구글 시트 행 삭제/숨김 필터·사건번호 int 처리 버그 수정.

15. **사건 목록 UI 개선** *(v4.4.6)*
   - **기일 열**: 디데이(D+/D-) 표시, 변론/판결선고기일 민트색, 날짜 YY.MM.DD 형식, CTkTextbox로 드래그 복사·수직 가운데.
   - **최근 업데이트 열**: 날짜 `26.03.11.` 형식 + 시간 줄바꿈, grid 수직 가운데 정렬.
   - **사건 목록**: 법원/사건번호·피고/사건명 줄바꿈·수직·수평 가운데, 비고 좌측 정렬, 행 높이 90px, grid+스페이서 수직 가운데.
   - **시트 버튼**: "시트" 텍스트 제거, 아이콘만 표시.

16. **기일 정보 캐싱 및 자동 조회 표기** *(v4.4.1)*
   - 기일 데이터를 개별 사건 시트가 아닌 크롤링 완료 시점에 추출해 `update_history.json`에 저장하고, 사건 목록에서는 캐시만 읽어 표시. 없으면 "기일 미정".
   - 최초 조회 성공 후 "변경없음"인 경우에도 '자동 조회' 열이 "자동 가능"으로 갱신되도록 수정.

17. **사건 목록 '기일' 열** *(v4.4.0)*
   - 구글 시트 개별 시트(일자·내용)에서 변론기일/판결선고기일과 날짜·시간을 파싱해 '기일' 열에 "00기일 YY.MM.DD.(HH:MM)" 형식으로 표시 (캐시 기반).

18. **아키텍처 정리** *(v4.3.99)*
   - 메인 GUI를 `gui/app_controller.py`의 `AppController`로 통합. `batch_gui_maker.py` 제거.
   - `utils/` 폴더 제거. `email_manager.py`를 `services/`로 이동.
   - ProcessController에서 Tkinter 의존성 제거, UI는 app 위임 및 ui_queue로만 처리.

19. **CLI 자동 실행(Auto-run) 안정화** *(v4.3.0)*
   - `--auto` 옵션으로 백그라운드 자동 조회. GUI와 동일한 2단계(브라우저 기동 -> 클릭 명령) 프로세스.
   - 다중 접속 시 프로필 락 지원.

20. **이메일 요약 리포트 디자인 개편** *(v4.3.0)*
   - **[사건번호 | 피고/사건명]** 구조의 HTML 표. 결과 상태별 그룹화.

21. **안정성 및 오류 처리 강화** *(v4.2.2)*
   - 사건 조회 실패 시 알림 및 실패 건 자동 재실행.

22. **알림메일 고도화** *(v4.2.0)*
   - 메일 본문 HTML 표·시트별 그룹화. GAS 웹 앱 연동 즉시 발송.
