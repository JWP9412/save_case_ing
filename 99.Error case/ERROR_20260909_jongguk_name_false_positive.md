
## 3. 근본 원인

`is_case_finalized`가 진행내용 **모든 칸**에서 `"종국" in str(value)` 부분 일치를 했다.

- 이름 **박종국** → `종국` 포함 → 오탐
- 칸 값/헤더가 문자열 **종국결과**만 있어도 → 오탐

정답 위치는 일반내용(기본내용) 표의 `basic['종국결과']` 실값뿐이다.

## 4. 왜 막지 못했나

- “종국” 글자만 있으면 종국이라는 느슨한 휴리스틱
