# 99.Error case — 사고 기록 보관소

이 폴더는 **실제로 발생한 장애·데이터 사고**를 기록하는 곳입니다.
같은 실수를 두 번 반복하지 않기 위해, 사고가 날 때마다 문서를 하나씩 추가합니다.

## 왜 만들었나

코드 리뷰나 CHANGELOG만으로는 "왜 이 방어 코드가 여기 있는지"를 나중에 알 수 없습니다.
사고 문서를 남겨두면, 몇 달 뒤 누군가 "이 조건문 불필요해 보이는데 지우자"라고 할 때
이 폴더를 보고 **지우면 안 되는 이유**를 알 수 있습니다.

## 파일 이름 규칙

```
ERROR_YYYYMMDD_짧은영문키워드.md
```

예: `ERROR_20260812_sheet_progress_wipe.md`

## 문서에 반드시 들어가야 할 항목

1. **증상** — 사용자가 실제로 겪은 현상 (로그 원문 포함)
2. **영향 범위** — 어떤 데이터가, 몇 건이나 손상됐는지
3. **근본 원인** — 코드 파일·행 번호까지 특정
4. **왜 막지 못했나** — 안전장치가 없었던 이유
5. **복구 방법** — 실제로 어떻게 되돌렸는지
6. **재발 방지 코드** — 어떤 가드를 어디에 넣었는지 (이걸 지우면 사고 재발)
7. **교훈 (체크리스트)** — 앞으로 코드 작성 시 지켜야 할 규칙
