# Google 인증 파일 안내 (포터블·개발 공통)
========================================

이 폴더에 **OAuth 클라이언트 비밀 파일**을 넣어야 구글 시트 연동이 됩니다.

## 넣을 파일

| 파일 | 용도 |
|------|------|
| `client_secret.json` | 앱 내 구글 로그인(OAuth) — **권장** |
| `service-account.json` | 서비스 계정 모드(선택, 고급) |

## 받는 방법 (client_secret.json)

1. [Google Cloud Console](https://console.cloud.google.com/) 에서 프로젝트 선택
2. **API 및 서비스 → 사용자 인증 정보**
3. **OAuth 2.0 클라이언트 ID** (데스크톱 앱) 만들기/다운로드
4. 받은 JSON 파일 이름을 `client_secret.json` 으로 바꿔 이 폴더에 저장

자세한 단계: 포터블 폴더 맨 위의 `README.TXT` "2. 구글 연동 파일" 참고.

## 그다음: 구글 시트 준비 (필수)

`client_secret.json`을 넣고 로그인만 하면 끝이 아닙니다. **저장할 구글 시트**도 준비해야 합니다.

**가장 쉬운 방법:** 앱의 「첫 실행 설정 가이드」에서  
[찾아보기] → [연동하기] → **[새 시트 자동 만들기]** 순서로 진행하세요.  
(시트·「사건 목록」탭·헤더까지 프로그램이 만듭니다.)

설정 → [첫 실행 가이드 열기] 로 언제든 다시 열 수 있습니다.

(참고·수동) 직접 시트를 만든 경우:
1. 탭 이름 `사건 목록`, 1행 `법원 / 사건번호 / 피고 / 사건명 / 비고`
2. 시트 URL을 가이드의 [기존 시트 연결]에 붙여넣기
3. 로그인한 계정이 시트를 **편집**할 수 있어야 함

자세한 안내: 포터블 폴더 맨 위 `README.TXT`

## 보안

- `client_secret.json` / `service-account.json` 은 **Git에 커밋하지 마세요.**
- USB·zip으로 넘길 때는 신뢰할 수 있는 사람에게만 전달하세요.
- 다른 PC에서는 프로그램 설정에서 **구글 계정 연동을 한 번** 해야 `data/google_user_token.json`이 생깁니다.
