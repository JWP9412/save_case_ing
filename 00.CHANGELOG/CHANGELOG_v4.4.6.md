# CHANGELOG v4.4.6

## 기일 열 UI 개선

- **디데이 표시**
  - 기일까지 남은/경과 일수 표시 (D-n, D-day, D+n). 최근 업데이트 열과 동일 양식.
  - D+ (과거) 초록색, D- (미래/오늘) 빨간색. 폰트 크기·굵기 최근 업데이트와 동일.
- **변론/판결선고기일 민트색**
  - `config.py` THEME에 `hearing_mint` 추가. 기일 열에서 "변론기일", "판결선고기일" 텍스트만 민트색 표시.
- **날짜 표기**
  - 로우 데이터 정제: 연도 2자리(YY.MM.DD) 형식. 06/6→2026 등 해석 후 표기.
  - `services/update_history.get_days_until_hearing(hearing_info)`로 디데이 계산.
- **드래그 복사·수직 가운데**
  - 기일 셀을 CTkTextbox로 변경해 드래그 선택 후 복사 가능. grid+스페이서로 수직 가운데 정렬.

## 최근 업데이트 열

- **날짜 형식**
  - `26.03.11.` + 줄바꿈 + `HH:MM:SS` 형식으로 표기. `history_ui` 실시간 갱신 시 동일 형식 적용.
- **수직 가운데 정렬**
  - f9에 grid_propagate(False), row 0/2 스페이서, row 1에 u_container 배치.

## 사건 목록 레이아웃

- **법원/사건번호·피고/사건명**
  - 줄바꿈(법원\n사건번호, 피고\n사건명), 수평 가운데, 수직 가운데(grid+스페이서). 텍스트박스 높이 52, 행 높이 90.
- **비고**
  - 좌측 정렬(justify="left"), 수직 가운데 유지.
- **수직 가운데 통일**
  - 모든 데이터 셀에 grid row 0/2 weight=1, row 1에 콘텐츠. grid_propagate(False) 및 스페이서 프레임으로 여백 균등 배분.
- **행 높이**
  - 78 → 90px. 기일 3줄 클리핑 방지.
