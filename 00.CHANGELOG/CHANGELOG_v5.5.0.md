# CHANGELOG v5.5.0

## v5.5.0 주요 변경 (2026-10-01)

공식 버전 흐름: **v5.4.0 → v5.5.0**

### Features & Improvements

- **알림메일을 사건 카드 하나로 묶음**
  - 같은 사건의 최신 업데이트와 결과 변경을 **카드 하나**에 담습니다. 시트명·바로가기는 한 번만 표시.
  - 구분 제목(최신 업데이트 / 결과 변경)은 15px·굵게·진한 색으로 표시.
  - 기록이 많은 사건(업데이트 행 + 결과변경 행)부터 위에 옵니다.
  - 글자 한도 안에 들어가면 한 통에 이어서 담고, 한 사건만으로 한도를 넘을 때만 `(이어짐 N)`으로 다음 메일에 잇습니다.
  - 조회 요약은 마지막 메일에만 포함.

- **메일 제목 구분**
  - 여러 통이면 제목에 `(1/2)`처럼 순번을 붙입니다.
  - 일시 형식은 `YYYY-MM-DD HH:MM:SS`로 맞춥니다. 시트가 Date로 바꾸면 GMT 장문이 되던 문제를 막습니다.

### Technical

- `config.py`: `APP_VERSION = "5.5.0"`.
- `services/email_manager.py`: 사건 단위 정렬·합친 카드(`_render_combined_case_card`)·긴 사건만 행 분할.
- `services/google_sheets.py`: 알림메일 시트 E열 `메일제목`, 일시 RAW 기록.
- `gas/SendNotificationMail.gs`: E열 제목 사용, 없으면 `(n/N)` + 일시 포맷 폴백.
- `scripts/test_mail_split.py`: 짧은 사건은 1통·시트명 1회, 긴 사건만 이어짐.

### 이전 버전 요약 (v5.4.0)

- 알림메일 카드형 HTML, 셀 한도 분할 발송, 깨진 태그 없는 안전 절단.

### GAS 다시 배포

시트 스크립트(`SendNotificationMail.gs`)를 붙여넣은 뒤 **웹 앱을 새 버전으로 배포**해야 제목 `(1/N)`이 적용됩니다.
