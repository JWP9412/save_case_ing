# Google Apps Script (GAS) - 알림메일 발송

Python 앱이 구글 시트의 **알림메일** 시트에 기록한 "대기" 행을 읽어, 해당 행의 **수신주소**로 실제 메일을 보내는 스크립트입니다. 수신 주소는 **프로그램의 설정(알림 수신 메일 주소)** 에서 입력합니다.

## 설정 방법 (즉시 발송용 웹 앱)

1. **구글 시트 열기**  
   case-ing에서 사용 중인 스프레드시트를 엽니다.

2. **Apps Script 열기**  
   상단 메뉴 **확장 프로그램** → **Apps Script**

3. **스크립트 붙여넣기**  
   기본 생성된 `function myFunction() {}` 를 삭제하고, `SendNotificationMail.gs` 파일 내용 전체를 복사해 붙여넣습니다. 저장(Ctrl+S).

4. **수신 이메일 주소**  
   - 프로그램 상단 **설정(⚙)** 에서 **알림 수신 메일 주소**를 입력하고 저장합니다.  
   - 메일 보내기 버튼을 누르면 이 주소가 시트의 "수신주소" 열에 함께 기록되며, GAS가 그 값을 읽어 발송합니다.

5. **한 번 수동 실행 (권한 부여)**  
   - 화면 상단의 함수 선택 드롭다운에서 **sendPendingNotificationEmails** 를 선택합니다.  
   - **실행** 버튼을 누릅니다.  
   - 처음 실행할 때 **"권한 필요"** 창이 뜨면:  
     `[권한 검토] → [본인 구글 계정 선택] → [고급] → [SendNotificationMail(으)로 이동(안전하지 않음)] → [허용]` 순서대로 눌러 권한을 부여합니다.

6. **웹 앱 배포 (즉시 발송용)**  
   - 상단 **배포** → **새 배포**  
   - 연필 아이콘(배포 유형 선택) 클릭 → **웹 앱** 선택  
   - **설명**: 예) "알림메일 즉시 발송"  
   - **실행 사용자**: **나**  
   - **액세스 권한**: **모든 사용자** (또는 "내부"만 사용할 경우 "내부")  
   - **배포** 클릭  
   - **웹 앱 URL**이 표시됩니다. 이 주소를 **전체 복사**합니다.

7. **프로그램에 URL 붙여넣기**  
   - case-ing 프로그램 **설정(⚙)** 창에서 **GAS 웹 앱 URL (즉시 발송용)** 입력칸에 위에서 복사한 URL을 붙여넣고 저장합니다.

이후 "최신 업데이트 모든 사건 내역 이메일 보내기" 버튼을 누르면 시트에 기록된 직후 **즉시** 해당 URL이 호출되어 메일이 발송됩니다.

## 발송 시점

- **즉시(웹 앱):** 위 6~7번처럼 웹 앱을 배포하고 URL을 설정해 두면, 버튼을 누를 때마다 즉시 발송됩니다.
- **수동:** Apps Script에서 `sendPendingNotificationEmails` 를 선택 후 **실행** 버튼으로 실행할 때마다 "대기" 행이 발송·"완료"로 갱신됩니다.
- **자동(트리거):** 왼쪽 **트리거**에서 1분마다 실행 등을 설정해 두면, URL을 설정하지 않아도 1분 이내에 자동 발송됩니다.

## 시트 구조 (Python 앱과 동일)

| A(일시) | B(수신주소) | C(메일내용) | D(발송상태) |
|--------|-------------|-------------|-------------|
| 2026-01-28 12:00:00 | your@email.com | \<html\>... | 대기 → 완료 |

발송 후 D열이 **완료** 또는 **실패: ...** 로 바뀝니다.
